# IRANSansWeb

IRANSansWeb is proprietary. Add licensed WOFF2 files to this directory, then replace the local-only `@font-face` source in `app/globals.css` with the matching `/fonts/...` URLs.

Until those licensed files are supplied, Persian pages use a locally installed IRANSansWeb when available and fall back to the bundled Vazirmatn font everywhere else.
